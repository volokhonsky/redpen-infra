# Идентификаторы элементов замечаний в DOM

Чем зацепиться за конкретное замечание на странице — в тесте, в отладке, в
ссылке. Документ переписан 2026-08-30: до этого он описывал только старый SPA
(`remarks.js`), которого больше нет, и учил цеплять селекторы, которых на
страницах читателя никогда не было.

Id замечания уникален **в пределах страницы**, а не глобально: адрес элемента —
это всегда пара «страница + id».

## На странице читателя (`<doc>/pages/<label>/index.html`)

Рисует `templates/js/page-view.js`, геометрию даёт
`templates/js/redpen-markers.js`.

| Элемент | Id | Где задаётся |
|---|---|---|
| кружок на скане | `circle-<id>` | `redpen-markers.js`, `createCircle()` |
| всплывающее окно | `popup-<id>` | `page-view.js`, `createPopup()` |
| распорка под попапом | `popup-spacer-<id>` | `page-view.js` |
| строка в панели справа | `panel-item-<id>` | `scripts/page_html.py` (пре-рендер) |

У кружка есть ещё `data-ann-id="<id>"` и классы: `circle`,
`circle--cat-<slug>` (категория приёма), `is-draft` у черновика,
`is-highlighted` у выделенного. Строка панели — `panel-item`,
`panel-item--<kind>`, `panel-item--cat-<slug>`.

Пример:

```python
page.click('#circle-ann-p012-3')
expect(page.locator('#popup-ann-p012-3')).to_be_visible()
```

Постоянная ссылка на одно замечание — `?only=<id>`: страница открывается с
единственным раскрытым замечанием и единственным маркером.

## В редакторе (`/app/`)

Экран страницы (`#/page/<doc>/<pageKey>`) рисует те же кружки тем же
`redpen-markers.js`, поэтому `circle-<id>` там означает ровно то же самое.
Дополнительно: `is-selected` у выбранного, `is-dragging` у перетаскиваемого,
`circle-__new__` — призрак ещё не созданного замечания под выбранной точкой.
Строки списка справа — `.app-page-item[data-id="<id>"]`.

## Замечания без id

Их нет. В актуальном контенте `id` обязателен: его требует формат
(`docs/remark_specification.md`), проставляет конвертер и генерирует сервер
(`srv-<время>-<hex>`) при создании через редактор. Прежний фолбэк «страница +
порядковый номер» вида `ann-page7-1` жил в SPA и удалён вместе с ним; в старых
материалах такие id встречаются как настоящие значения поля `id`, а не как
вычисленные на лету.
