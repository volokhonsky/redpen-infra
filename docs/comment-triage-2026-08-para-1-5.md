## Как читать адреса страниц

**Нумерация в исходнике не совпадает с нумерацией проекта.** Метки `[[page::N]]` в
основном соответствуют *файлам текстового слоя* (`text/page_NNN.json`), которые сдвинуты
на +1 относительно печатной страницы: `[[page::8]]` → печатная стр. 7 →
`annotations/page_007.md`. Но на «открывающих» страницах параграфов сдвига нет:
`[[page::21]]`, `[[page::22]]`, `[[page::29]]`, `[[page::30]]`, `[[page::59]]`,
`[[page::60]]`, `[[page::61]]` указывают на печатные 21, 22, 29, 30, 59, 60, 61.
Поэтому **все адреса ниже проставлены по содержанию** (сверено с текстовым слоем), а не по
меткам исходника. Колонка «стр.» = печатная страница = имя файла аннотаций.
